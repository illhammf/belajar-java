# ♻️ EcoCycle — Sistem Pengelolaan Sampah Rumah Tangga dan Bank Sampah Digital

## 📖 Tentang Project

**EcoCycle** adalah project pengembangan aplikasi menggunakan bahasa pemrograman Java untuk membantu proses pengelolaan sampah rumah tangga dan bank sampah digital.

Project ini dikembangkan secara bertahap sebagai penerapan materi mata kuliah **Pemrograman Berorientasi Objek (PBO)** selama 14 pertemuan. Setiap pertemuan akan menambahkan atau menyempurnakan fitur berdasarkan materi yang telah dipelajari.

Project ini juga direncanakan untuk dikembangkan lebih lanjut melalui integrasi dengan mata kuliah Basis Data.

## 🎯 Tujuan Project

* Menerapkan materi pembelajaran Java ke dalam sebuah project berkelanjutan.
* Memahami penerapan konsep pemrograman melalui studi kasus.
* Mengembangkan aplikasi secara bertahap berdasarkan materi setiap pertemuan.
* Menerapkan konsep Object-Oriented Programming (OOP) sesuai materi yang dipelajari.
* Mempersiapkan integrasi aplikasi dengan database.
* Mendokumentasikan proses pengembangan sebagai bahan pembelajaran dan portofolio GitHub.

## 🌱 Gambaran Fitur

Fitur yang direncanakan untuk dikembangkan meliputi:

1. Pengelolaan data nasabah.
2. Pengelolaan kategori dan harga sampah.
3. Pencatatan setoran sampah.
4. Perhitungan nilai setoran.
5. Pengelolaan saldo dan riwayat transaksi.
6. Penjadwalan penjemputan sampah.
7. Pembuatan laporan pengelolaan sampah.
8. Penyimpanan data menggunakan database.
9. Pengembangan antarmuka aplikasi sesuai kebutuhan.

Fitur tersebut merupakan rencana pengembangan dan akan ditambahkan secara bertahap sesuai materi perkuliahan.

## 🛠️ Teknologi

* **Bahasa Pemrograman:** Java
* **Code Editor:** Visual Studio Code
* **Database:** Direncanakan menggunakan MySQL, menyesuaikan materi Basis Data
* **Platform Awal:** Aplikasi berbasis console

Teknologi dan arsitektur dapat berkembang selama proses pembelajaran.
